ARTELVA — ATUALIZAÇÃO DE FOTOS — 27/11/2026

COMO SUBIR NO SITE
1. Extraia este ZIP no computador.
2. No repositório labuxa/artelva, abra a raiz do projeto e use Add file > Upload files.
3. Envie os arquivos e as pastas extraídos, preservando assets/images e servicos. O index.html deve ficar na raiz do repositório.
4. Confirme a substituição dos arquivos existentes e salve o commit na branch main.
5. Aguarde a publicação do GitHub Pages e confira o site. Se ainda aparecer a versão anterior, atualize com Ctrl+F5.

Este é um pacote de atualização: mantenha os demais arquivos que já existem no repositório. O ZIP não deve ser enviado fechado e não é preciso criar outra pasta acima do index.html.
